## 3. Methodology

### 3.1 Approach
The assessment was conducted using a structured questionnaire covering the following dimensions:

```
┌─────────────────────────────────────────────────┐
│           AI SKILLS ASSESSMENT FRAMEWORK         │
├──────────────┬──────────────┬───────────────────┤
│  KNOWLEDGE   │   SKILLS     │   EXPERIENCE      │
│              │              │                   │
│ • Core AI/ML │ • Tools &    │ • Projects        │
│   concepts   │   frameworks │   completed       │
│ • Deep       │ • Cloud AI   │ • Production      │
│   Learning   │   services   │   deployments     │
│ • NLP        │ • LLM/GenAI  │ • Open-source     │
│ • Computer   │ • MLOps      │   contributions   │
│   Vision     │ • Data       │ • Business impact │
│ • GenAI      │   engineering│                   │
│ • Ethics     │              │                   │
├──────────────┴──────────────┴───────────────────┤
│  TRAINING & CERTIFICATIONS  │  CURRENT AI USAGE │
│ • Courses completed         │ • AI tools in use │
│ • Active learning           │ • Productivity    │
│ • Desired training          │   improvements    │
│ • Preferred format          │ • AI opportunities│
└─────────────────────────────┴───────────────────┘
```

### 3.2 Rating Scale
All self-assessments used a 5-point proficiency scale:

| Rating | Level | Description |
|:---:|-------|-------------|
| 1 | No Knowledge | No exposure or understanding of the topic |
| 2 | Basic Awareness | Has heard of the topic; understands it at a high level |
| 3 | Working Knowledge | Can apply basic concepts; has done tutorials or small projects |
| 4 | Proficient | Can independently build and deliver AI solutions |
| 5 | Expert | Deep expertise; can architect, lead, and mentor others |
